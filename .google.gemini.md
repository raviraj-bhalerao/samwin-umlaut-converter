## 2. Evaluation Assignment: Programming Task
**Problem:** samwin stores names with umlauts (Ä, Ö, Ü, ß). Older devices replace these with (AE, OE, UE, SS). Names are stored in CAPITAL LETTERS.
- **Step 1:** Convert replacement letters back to umlauts (e.g., KOESTNER -> KÖSTNER).
- **Step 2:** Generate all possible variations/permutations (e.g., RUESSWURM -> RUESSWURM, RÜBWURM, RUERWURM, RÜSSWURM).
- **Step 3:** Generate a SQL `WHERE` clause for all variations.
- **Test Cases:** - KOESTNER
  - RUESSWURM
  - DUERMUELLER
  - JAEAESKELAEINEN
  - GROSSSCHAEDL

## 3. Current Implementation Status
